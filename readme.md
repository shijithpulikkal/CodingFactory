# Business Analytics Solutions Across SQL, BigQuery, Python & Power BI

## 📊 Project Overview

This repository demonstrates how the same business analytics problems can be solved using multiple technologies:

- Microsoft SQL Server (SSMS)
- Google BigQuery
- Python (Google Colab)
- Power BI DAX

The objective is to compare different analytical approaches while working with the same dataset and business requirements.

The project uses the **Superstore Dataset** and implements a collection of intermediate-to-advanced analytical scenarios commonly used in Business Intelligence, Data Analytics, and Data Science.

## 🎯 Business Questions Solved

### 1. Highest Spending Customers by Year
Identify the top revenue-generating customer for each year.

### 2. Running Total
Calculate cumulative sales over time.

### 3. Month-over-Month (MoM) Sales Growth %
Measure sales growth compared with the previous month.

### 4. 3-Month Moving Average of Sales
Analyze sales trends using rolling averages.

### 5. Year-over-Year (YoY) Growth %
Compare current year performance with the previous year.

### 6. New vs Returning Customers per Month
Classify customers based on purchase history.

### 7. Top N Products per Category
Rank products within each category based on sales.

### 8. Cumulative Distinct Customers Over Time
Track customer acquisition growth over time.

### 9. Customer Retention Rate (Month-over-Month)
Measure customer retention between consecutive months.

### 10. RFM Segmentation
Segment customers based on:

- Recency
- Frequency
- Monetary Value

### 11. Percentage of Total Sales by Category
Determine each category's contribution to overall sales.

### 12. Market Basket Analysis
Identify product combinations frequently purchased together.

### 13. Contribution Margin by Region
Analyze regional profitability performance.

### 14. Pareto Analysis (80/20 Rule)
Identify products or customers contributing most of the revenue.

### 15. Cohort Analysis
Analyze customer behavior and retention across acquisition cohorts.
